# Кори курсӣ

**Мавзӯъ:** Нақши воситаҳои аёнӣ ва мултимедиявӣ дар таълими забони англисӣ

## Файли асосӣ

`Кори_курсӣ_Воситаҳои_аёнӣ_ва_мултимедиявӣ.docx` — ҳуҷҷати пурраи Microsoft Word.

## Сохтор

- Саҳифаи унвонӣ (бо ҷойҳои холӣ барои номи муассиса, донишҷӯ ва роҳбар)
- Мундариҷа
- Муқаддима (мубрамият, дараҷаи омӯзиш, мақсад, вазифаҳо, объект, предмет, усулҳо, аҳамияти назариявӣ ва амалӣ, сохтор)
- Боби 1 — асосҳои назариявӣ (1.1, 1.2, 1.3)
- Боби 2 — имкониятҳои методӣ (2.1, 2.2, 2.3)
- Боби 3 — ҷанбаҳои амалӣ (3.1, 3.2, 3.3)
- Хулоса
- Рӯйхати адабиёти истифодашуда (27 манбаи воқеӣ)
- Замима (нақшаи намунавии дарс ва варақаи худбаҳодиҳӣ)

Дар кор 9 ҷадвал ва 5 расм (диаграммаи сутунӣ, доиравӣ, графикӣ хаттӣ, схемаи рамзгузории дугона ва модели TPACK) ҷойгир карда шудаанд. Маълумоти ададии озмоишӣ дар ҳама ҷо возеҳ ҳамчун **намунавӣ (шартӣ)** нишон дода шудааст.

## Танзимоти техникӣ

Times New Roman 14, фосилаи 1,5, ҳамворкунӣ Justify, ҳошияҳо: чап 3 см, рост 1,5 см, боло/поён 2 см, сархат 1,25 см. Ҳаҷми ҳисобшуда: **38 саҳифа** (бо метрикаи шрифти Times тафтиш карда шуд; дар нусхаҳои гуногуни Word/шрифтҳои насбшуда ±1 саҳифа тағйир ёфта метавонад — пеш аз чоп рақамҳои мундариҷаро як бор бо ҳуҷҷати кушодашуда муқоиса кунед).

## Бозсозӣ

Скриптҳои сохтани ҳуҷҷат дар папкаи `src/` ҷойгиранд (`build.py` — сохтан, `estimate2.py` — ҳисоби саҳифаҳо ва навсозии мундариҷа).
