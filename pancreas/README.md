# Кори курсӣ: «Секретсияи экзокринии ғадуди зери меъда ва механизмҳои танзими он»

Файли тайёр: **`pancreas/docx/Kori_kursi_sekretsiyai_pankreas.docx`** (37 саҳифа, A4).
Фан: физиологияи нормалӣ. Забон: тоҷикӣ.

## Сохтор
| Қисм | Саҳифа |
|---|---|
| Саҳифаи аввал (унвон) | 1 |
| Мундариҷа | 2 |
| Муқаддима | 3–5 |
| Боби 1 — хусусиятҳои морфофунксионалӣ (1.1–1.3) | 6–19 |
| Боби 2 — механизмҳои танзим (2.1–2.3) | 20–31 |

| Рӯйхати адабиёт (29 сарчашма) | 35–37 |

7 ҷадвал, 8 расм, 1 формула (1.1). Ҳамаи ҷадвалҳо/расмҳо дар матн пеш аз омадан ишора шудаанд.

## Танзимот
Times New Roman 14 pt, интервали 1,5, матн аз рӯи баробарӣ, ҳошияҳо 3/1,5/2/2 см,
абзатс 1,25 см, рақами саҳифа дар поён (марказ), сарлавҳаҳо рақамгузорӣ шудаанд.

## Сохтани дубора
```bash
python3 -m venv .venv && .venv/bin/pip install python-docx pillow matplotlib
.venv/bin/python pancreas/src/figures.py   # расмҳо -> pancreas/figures/*.png
.venv/bin/python pancreas/src/build.py     # docx -> pancreas/docx/*.docx
```

## Эзоҳҳо
- Нақшаи бобҳо (2 боб × 3 зербоб) тибқи интихоби корбар тартиб дода шудааст.
- Маълумоти рақамӣ (ҳаҷми секрет, таносуби ферментҳо, динамика) аз адабиёт гирифта шуда,
  ҷойҳои тақрибӣ дар матн ва зери расмҳо ҳамчун «тақрибӣ/намунавӣ» қайд шудаанд.
- Майдонҳои саҳифаи аввал холӣ гузошта шудаанд.
