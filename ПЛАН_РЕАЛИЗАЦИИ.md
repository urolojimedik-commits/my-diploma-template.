# План создания системы автоматизации подготовки курсовых и дипломных работ

> Документ составлен после изучения репозитория `my-diploma-template` (ветка `arena/0e8e8eac-my-diploma-template`, коммит `f540ace`).

## 1. Анализ существующего проекта

### Что уже есть
- **Academic Pandoc template** (Quarto) — три типа документов: `article/`, `presentation/`, `thesis/`.
- Рендер в HTML, DOCX, PDF, EPUB, PPTX, TeX через `_quarto.yml` и `_metadata.yml`.
- Библиография BibTeX (`references.bib`, `sources.bib`) + CSL `chicago-author-date` / `chicago-note-bibliography`.
- Кросс-ссылки Quarto: `{#fig-...}`, `{#tbl-...}`, `@fig-...`.
- CI: `.github/workflows/quarto.yml` — `npm run render` → `quarto render`.
- Стили бренда `_brand.yml`, шаблоны `_layouts/default.html`.

### Чего нет
1. Приёма темы и генерации плана — только ручное редактирование Markdown.
2. Поиска реальных источников — `references.bib` заполняется вручную.
3. Написания академического текста — примеры заполнены lorem ipsum «All human beings...».
4. Программного создания таблиц/графиков — отсутствует.
5. Русского языка — `lang: en-US`, ГОСТ не поддерживается.
6. Проверки достоверности DOI/статистики.
7. Единого pipeline «тема → план → источники → текст → DOCX/PDF».

### Ограничения окружения
- Quarto/Pandoc не установлены, `apt` без сети `deb.debian.org`.
- Доступен Python 3.11 + pip (через venv), интернет к `registry.npmjs.org`, `pypi.org`, `github.com`, `api.github.com`.
- Решение: реализовать сборку на Python (`python-docx`, `matplotlib`, `reportlab`/`weasyprint`) + опциональная интеграция Quarto/Pandoc, когда они доступны.

## 2. Архитектура новой системы

```
my-diploma-template./
├── _quarto.yml, thesis/, article/, presentation/  # сохранены без изменений
├── src/diploma_builder/          # ядро Python-пакета
│   ├── __init__.py
│   ├── config.py                 # модели данных, ГОСТ-настройки
│   ├── planner.py                # 1→2: тема → подробный план глав
│   ├── search.py                 # 3: поиск реальных источников (Crossref/OpenAlex)
│   ├── writer.py                 # 4: академический текст с проверяемыми ссылками
│   ├── figures.py                # 5: таблицы, графики, диаграммы (matplotlib)
│   ├── bibliography.py           # 7: список литературы (ГОСТ Р 7.0.5-2018)
│   ├── docx_builder.py           # 8: DOCX (python-docx, ГОСТ)
│   ├── pdf_builder.py            # 8: PDF (reportlab + weasyprint fallback)
│   ├── quarto_builder.py         # 8: генерация .qmd + вызов quarto/pandoc
│   ├── pipeline.py               # оркестрация всех этапов
│   ├── cli.py                    # CLI интерфейс
│   └── web/
│       ├── app.py                # Flask веб-приложение (10: скачивание)
│       └── templates/            # HTML шаблоны
├── templates/                    # Quarto шаблоны на русском
│   ├── thesis_ru/
│   │   ├── _quarto.yml
│   │   ├── _metadata.yml
│   │   └── index.qmd
│   └── gost_reference.docx       # (генерируется)
├── scripts/
│   ├── generate_example.py       # демо-сборка
│   └── verify_sources.py
├── examples/
│   └── demo_цифровизация/        # готовый пример работы
├── requirements.txt
└── ПЛАН_РЕАЛИЗАЦИИ.md (этот файл)
```

### Принципы
- **Не выдумывать источники**: все DOI проверяются через `api.crossref.org/works/{DOI}`; статистика — только из открытых данных Росстата/ЦБ или помечается «Учебный пример».
- **Двухуровневая сборка**: Python (всегда) + Quarto/Pandoc (если установлены).
- **Русский язык по умолчанию**: `lang: ru`, ГОСТ, Times New Roman 14pt, интервал 1.5.
- **Кэширование**: поиск кэшируется в `data/cache/`.

|---|------------|--------|------------|
| 1 | Принимать тему | `config.py`, `cli.py`, `web/app.py` | CLI `--topic`, веб-форма, YAML-конфиг `project.yaml` |
| 2 | План и структура глав | `planner.py` | Эвристика по типу работы (курсовая/диплом/ВКР/магистерская) + дисциплины → ГОСТ-структура: титул, содержание, введение, 3 главы, заключение, литература, приложения. Иерархический JSON + Markdown оглавление |

| 6 | Подписи и нумерация | `docx_builder.py`, `quarto_builder.py` | «Рисунок N — ...», «Таблица N — ...», сквозная нумерация, автоматический Список рисунков/таблиц |
| 7 | Список литературы | `bibliography.py` | Генерация `references.bib` + ГОСТ Р 7.0.5-2018 список + сортировка, проверка DOI |
| 8 | DOCX и PDF | `docx_builder.py`, `pdf_builder.py`, `quarto_builder.py` | python-docx (Times New Roman, поля ГОСТ) + reportlab/weasyprint; при наличии quarto — `quarto render` |
| 9 | Русский язык | везде | `lang: ru`, русские заголовки, кавычки «ёлочки», ГОСТ-цитирование, шрифты с кириллицей |
| 10 | Скачивание | `web/app.py` | Flask: `/` форма → `/build` → `/download/<fmt>`; отдача файлов + preview |

## 5. Технические решения

### Поиск источников
```python
# Crossref: https://api.crossref.org/works?query=цифровизация+госуправление&rows=10&filter=from-pub-date:2015
# OpenAlex: https://api.openalex.org/works?search=цифровизация&filter=publication_year:2015-2024
# Проверка: GET https://api.crossref.org/works/{DOI} → 200 = валиден
```

### ГОСТ оформление
- Поля: левое 30мм, правое 15мм, верх/низ 20мм
- Шрифт: Times New Roman 14pt (DOCX), DejaVu Serif / Liberation Serif (PDF)
- Интервал 1.5, красная строка 1.25см
- Нумерация: «Рисунок 1 — Название» (по центру, 12pt), «Таблица 1 — ...» (слева)
- Список литературы: ГОСТ Р 7.0.5-2018, сортировка по алфавиту, нумерованный

### Безопасность
- Нет выдуманных DOI — каждый проходит проверку
- Графики с учебными данными имеют подпись «Источник: учебный пример, данные условные»
- Предупреждение в веб-интерфейсе об академической добросовестности
