Ин ҷузвдон асбобҳои навиштани корҳои курсӣ барои **Кафедраи фанҳои дақиқ ва тиббии Донишкадаи илмҳои дақиқ ва технологияи Тоҷикистон дар шаҳри Хуҷанд** мебошад.

## Файлҳо

| Файл | Чӣ аст |
| :--- | :--- |
| [`PROMPT_KORI_KURSI.md`](PROMPT_KORI_KURSI.md) | Промти пурра (3 қисм), ҳисоби ҳаҷм, ҷадвали санҷиш, рӯйхати 30 мавзӯъ |
| [`PROMPT_KORI_KURSI.docx`](PROMPT_KORI_KURSI.docx) | Ҳамон ҳуҷҷат дар шакли Word — барои чоп ва тақсим кардан |
| [`01_Elastografiya.md`](01_Elastografiya.md) | НАМУНАИ СОХТОР: ҳамаи сарлавҳаҳо, ҷойҳои ҷадвалҳо ва ҳисобҳо омодаанд |
| [`01_Elastografiya.docx`](01_Elastografiya.docx) | Ҳамон намуна дар Word — формати пурраи стандартӣ |
| [`scripts/build_docx.py`](scripts/build_docx.py) | Markdown → Word бо вараки унвон, мундариҷа, рақами саҳифа, ҷадвалҳо |
| [`scripts/check_coursework.py`](scripts/check_coursework.py) | Санҷиши худкор: ҳаҷм, сохтор, иқтибос, ҷумлаи дароз, ибораҳои холӣ |

## Оғоз (2 дақиқа)

```bash
# 1. Муҳит (як маротиба)
python3 -m venv .venv
.venv/bin/pip install python-docx

# 2. Файли нав аз намуна созед
cp coursework/01_Elastografiya.md coursework/02_CEUS.md

# 3. Матнро нависед ё аз модел гиред, баъд файли Word созед
.venv/bin/python coursework/scripts/build_docx.py coursework/02_CEUS.md

# 4. Пеш аз супоридан санҷед
.venv/bin/python coursework/scripts/check_coursework.py coursework/02_CEUS.md
```

## Синтаксиси Markdown, ки скрипт мефаҳмад

```markdown
# БАНДИ 1. НОМИ БАНД          → сарлавҳаи ғафс, дар марказ, ҳарфҳои калон
## 1.1. Зербанд               → сарлавҳаи ғафс, аз чап
### Зербанди хурд             → сарлавҳаи ғафси хурд
¶ Абзаци оддӣ                 → TNR 14, 1,5, саршавии 1,25 см, justify
- Рӯйхат                      → рӯйхати нуқтадор
1. Рӯйхати рақамӣ             → рӯйхати рақамӣ
**ғафс** ва *моил*            → таъкид
> эзоҳ                        → матни хурди фосиладор

Ҷадвали 1.1 — Ном            → унвони ҷадвал (дар болои ҷадвал)
| A | B |
| :--- | :--- |
| 1 | 2 |
```

Қоида: сатри «Ҷадвали 1.1 — Ном» бояд **бевосита пеш аз** ҷадвал навишта шавад — скрипт онҳоро якҷоя мекунад.

## Танзимоти донишкада

Дар `scripts/build_docx.py` бахши `INSTITUTION`-ро як бор тағйир диҳед — ном, факултет, кафедра, сол ва ҷойҳои холӣ ба ҳамаи корҳои навбатӣ чоп мешаванд.

## Чӣ тавр кори комилро гирифтан мумкин

Промти `PROMPT_KORI_KURSI.md` барои модел аст. Дастури кӯтоҳ:

1. Промти пурра + рӯйхати мавзӯъҳо → модел нақша медиҳад.
2. «ок» → «Банди 1-ро навис» → «Идома» …
3. Банди 2 → Банди 3 → хулоса → адабиёт → замимаҳо.
4. Матнро дар файли `.md` гузоред → `build_docx.py` → `check_coursework.py`.

⚠️ **Муҳим:** модел рақам, сана, ном ва омори клиникиро ихтироъ намекунад. Ҳамаи ҷойҳои «______» ва «[дақиқ кардан лозим]»-ро худатон аз сарчашмаи аслӣ пур кунед. Ин масъулияти шумост, на кори модел.
