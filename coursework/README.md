### Чӣ тавр кушодан

1. Файли `01_Elastografiya.docx`-ро дар Word кушоед.
2. Word мепурсад: «This document contains fields that may refer to other files. Do you want to update the fields?» → **Yes**. Мундариҷа худкор сохта мешавад.
3. Агар мундариҷа нашуда бошад: клик дар ҷои мундариҷа → `F9` → **Update entire table**.
4. Ҳамаи «______» ва «[дақиқ кардан лозим]»-ро аз маълумоти воқеии муассиса пур кунед.
5. Дар `Вставка → Номери страницы` тафтиш кунед, ки рақами саҳифа дар поёни марказ аст ва вараки унвон рақам надорад.

## Корҳои навбатӣ — 29 мавзӯъ

Мавзӯи 1 намунаи пурра аст. Барои ҳар мавзӯи дигар ҳамин тартибро такрор кунед:

```bash
# 1. Муҳит (як маротиба)
python3 -m venv .venv
.venv/bin/pip install python-docx

# 2. Ҷузвдон аз намуна созед
cp -r coursework/01_Elastografiya coursework/02_CEUS
rm coursework/02_CEUS/*.md
echo "Ултрасадои контрастӣ (CEUS): асосҳои метод ва истифода дар ташхиси бемориҳои узвҳои дохилӣ" > coursework/02_CEUS/topic.txt

# 3. Файлҳоро нависед (00_Muqaddima.md, 10_Bandi_1.md, …)
#    — матнро аз промт гиред ва дар ҳамин файлҳо гузоред

# 4. Файли Word созед ва санҷед
.venv/bin/python coursework/scripts/build_docx.py coursework/02_CEUS
.venv/bin/python coursework/scripts/check_coursework.py coursework/02_CEUS/00_Muqaddima.md
```

Скрипт ҳамаи файлҳои `.md`-и ҷузвдонро **бо тартиби алифбоӣ** ҷамъ мекунад — барои ҳамин пеш аз ном рақам мегузорем (`00_`, `10_`, `20_` …).

## Синтаксиси Markdown, ки скрипт мефаҳмад

```markdown
# БАНДИ 1. НОМИ БАНД          → сарлавҳаи ғафс, дар марказ, ҳарфҳои калон
## 1.1. Зербанд               → сарлавҳаи ғафс, аз чап
### Зербанди хурд             → сарлавҳаи ғафси хурд
¶ Абзаци оддӣ                 → TNR 14, 1,5, саршавии 1,25 см, justify
- Рӯйхат                      → рӯйхати нуқтадор
1. Рӯйхати рақамӣ             → рӯйхати рақамӣ
**ғафс** ва *моил*            → таъкид
> эзоҳ                        → матни хурди фосиладор

Ҷадвали 1.1 — Ном            → унвони ҷадвал (дар болои ҷадвал)
| A | B |
| :--- | :--- |
| 1 | 2 |
```

**Муҳим:** сатри `Ҷадвали 1.1 — Ном` бояд **бевосита пеш аз** ҷадвал бошад — скрипт онҳоро якҷоя мекунад ва унвонро дар болои ҷадвал мегузорад.

## Танзимоти донишкада

Дар `scripts/build_docx.py` бахши `INSTITUTION`-ро як бор тағйир диҳед — ном, факултет, кафедра, сол ва ҷойҳои холӣ ба ҳамаи корҳои навбатӣ чоп мешаванд.

## ⚠️ Масъулият

Модел нақша, мантиқ ва матн медиҳад. Масъулияти рақамҳо, санаҳои нашр, номҳо ва адолати хулоса **бо иҷрокунанда** мемонад. Дар ин кор ҳамаи маълумоти клиникии воқеӣ бо «______» ишора шудааст — онҳоро аз сарчашмаи аслӣ пур кунед. Пеш аз супоридан ҳадди ақал ду ҷойро аз манбаи аслӣ санҷед.
