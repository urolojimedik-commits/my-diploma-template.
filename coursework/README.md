# Курсӣ: «Роҳҳои омӯзиши сохтори ҷумла дар таълими забони англисӣ»

Файли тайёр: **`coursework/docx/Kori_kursi_sokhtori_jumla.docx`** (38 саҳифа, A4).

## Сохтор
| Қисм | Саҳифа |
|---|---|
| Саҳифаи аввал (унвон) | 1 |
| Мундариҷа | 2 |
| Муқаддима | 3–5 |
| Боби 1 (3 зербоб) | 6–14 |
| Боби 2 (3 зербоб) | 15–23 |
| Боби 3 (3 зербоб) | 24–32 |
| Хулоса | 33–35 |
| Рӯйхати адабиёт (32 сарчашма) | 36–38 |

## Танзимот
Times New Roman 14 pt, интервали 1,5, матн аз рӯи баробарӣ (justify), ҳошияҳо 3/1,5/2/2 см,
абзатс 1,25 см, рақами саҳифа дар поён (марказ), сарлавҳаҳо рақамгузорӣ шудаанд.

## Сохтани дубора
```bash
.venv/bin/python coursework/src/figures.py   # расмҳо -> coursework/figures/*.png
.venv/bin/python coursework/src/build.py     # docx   -> coursework/docx/Kori_kursi_sokhtori_jumla.docx
```
Барои сохтани docx танҳо `python-docx` лозим аст; барои расмҳо `matplotlib`.

## Эзоҳҳо (фарзияҳо)
- Нақшаи бобҳо аз ҷониби муаллифи кор тартиб дода шудааст (дар супориш танҳо мавзӯъ дода шудааст).
- Ҳамаи маълумоти рақамӣ (42 омӯзгор, 64 донишҷӯ, динамикаи 8 ҳафта, фоизи китобҳои дарсӣ)
  **намунавӣ/шартӣ** буда, дар матн ва зери ҷадвалҳо ҳамин тавр қайд шудааст.
- Майдонҳои саҳифаи аввал (донишгоҳ, факултет, кафедра, донишҷӯ, роҳбар, шаҳр, сол) холӣ гузошта шудаанд.

## Файлҳои манбаъ
- `src/cw.py` — геометрия, ченакҳо, симуляцияи саҳифабандӣ
- `src/figures.py` — сохтани 7 расм (PNG)
- `src/front.py` — саҳифаи аввал, мундариҷа, муқаддима
- `src/ch1.py`, `src/ch2.py`, `src/ch3.py` — бобҳо (матн, ҷадвалҳо, расмҳо, формула)
- `src/back.py` — хулоса ва рӯйхати адабиёт
- `src/build.py` — сохтани файли `.docx`
