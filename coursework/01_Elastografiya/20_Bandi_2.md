# БАНДИ 2. ТАҲЛИЛИ ИСТИФОДАИ КЛИНИКИИ ЭЛАСТОГРАФИЯ

Дар ин банд эластография дар шароити амал таҳлил мешавад. Аввал вазъи имрӯзаи истифода дида мешавад. Баъд нишондиҳандаҳои самаранокӣ бо формула ҳисоб карда мешаванд. Дар охир омилҳои мушкилот ҷамъбаст мегарданд. Ҳамаи рақамҳои корӣ намунаанд. Ҷойи онҳоро бояд бо маълумоти воқеии муассиса иваз кард. Ин ҷойҳо бо аломати «______» нишон дода шудаанд.

## 2.1. Вазъи имрӯзаи истифода дар ташхис

Эластография имрӯз дар се самти асосӣ истифода мешавад. Аввал — ташхиси фибрози ҷигар. Дуюм — арзёбии омосҳои сина ва сипаршакл. Сеюм — назорати ҷараёни табобат ва муайян кардани омосҳои шубҳанок дар гиреҳҳои лимфавӣ.

Дар ҷигар метод маъмултарин аст. Ченак дар як нуқта бо даҳ ченак гузаронида мешавад. Натиҷа дар кПа ё м/с ифода меёбад. Тибқи маълумоти адабиёт, эластографияи транзиентӣ дар фибрози ҷигар ҳассосияти 80–90 % дорад [2, 96-б.]. Ин рақам ба биопсия наздик аст. Бартарии асосӣ дар он аст, ки метод бе дард ва бе хавф мегузарад.

Дар фибрози ҷигар чор марҳилаи асосӣ ҷудо карда мешавад. Марҳилаи якум фибрози сабук аст. Марҳилаи дуюм — фибрози миёна. Марҳилаи сеюм — фибрози вазнин. Марҳилаи чорум — сирроз. Ҳар марҳила қимати муайяни сахтиро дорад. Ин тақсим дар Ҷадвали 2.1 оварда шудааст.

| :-: | :--- | :-: | :--- |
| F0 | Ҷигари солим | < 5,0 | Меъёр |
| F1 | Фибрози сабук | 5,0–7,0 | Оғоз |
| F2 | Фибрози миёна | 7,0–9,5 | Пешрафт |
| F3 | Фибрози вазнин | 9,5–12,5 | Хатар |

Дар сина метод барои фарқгузории омоси хушсифат ва бадсифат истифода мешавад. Қимати ҳаддии маъмул 80–100 кПа аст. Агар сахтӣ аз ин ҳадд зиёд бошад, эҳтимоли бадсифат будан баланд мешавад. Дар сипаршакл метод барои интихоби гиреҳ барои биопсия кӯмак мекунад. Ҳамин тавр шумораи биопсияҳои нолозим дар амал кам мешавад.

Дар узвҳои дохилӣ, ба монанди гурда ва ҷигар, метод ҳанӯз дар марҳилаи инкишоф аст. Дақиқии он аз сина ва сипаршакл пасттар мебошад. Вале дар чен кардани омоси гурда ва фарқгузории он аз кистаҳо натиҷаи хуб медиҳад [3, 142-б.].

Дар Тоҷикистон татбиқи метод нобаробар аст. Дар марказҳои калони шаҳрҳо дастгоҳҳои SWE мавҷуданд. Дар сатҳи ноҳиявӣ асосан ултрасадои анъанавӣ истифода мешавад. Дар шаҳри Хуҷанд ______ муассиса эластографияро доранд. Шумораи табибоне, ки омӯзиши расмӣ гузаштаанд, ______ нафар аст. Ин рақамҳоро бояд аз маълумоти расмии шуъбаи тандурустӣ гирифт.


Синну сол ба сахтии бофта таъсир мерасонад. Дар одамони калонсол бофтаи ҷигар табиатан сахттар мешавад. Ин фарқият дар ченак бояд ба назар гирифта шавад. Тадқиқот нишон медиҳад, ки фарқияти миёнаи сахтӣ дар гурӯҳҳои синнусолӣ то 1,5 кПа мерасад [7, 404-б.]. Ҷинс низ таъсир дорад, вале ин таъсир нисбатан кам аст.

Ҳиссаи ҳар узв бо формула ҳисоб мешавад:

Ҳисса, % = (Шумораи таҳқиқи узв / Шумораи умумӣ) × 100 % .

Намунаи ҳисоб. Агар дар як моҳ 240 таҳқиқ гузаронида шавад ва аз онҳо 96 ба ҷигар рост ояд:

Ҳисса = (96 / 240) × 100 % = 40 % .

Ин рақам нишон медиҳад, ки ҷигар самти асосии кор аст. Бинобар ин имкониятҳо барои ин узв бештар таҳким ёбанд. Ин натиҷа дар Банди 3 ҳангоми тақсими захира ба назар гирифта мешавад.

Барои муқоиса метавон маълумоти ду солро гирифт. Агар соли гузашта 180 таҳқиқ ва соли ҷорӣ 240 таҳқиқ гузаронида шуда бошад, афзоиш чунин ҳисоб мешавад:

Афзоиш, % = ((240 − 180) / 180) × 100 % = 33,3 % .

Ин рақам барои баҳодиҳии талабот муҳим аст. Афзоиши зиёд нишон медиҳад, ки захираи дастгоҳ ва вақти табибон зиёд карда шаванд.

## 2.2. Ҳисоби нишондиҳандаҳои самаранокӣ

Барои арзёбии дақиқӣ ду маҷмӯи натиҷа муқоиса мешавад. Маҷмӯи якум натиҷаи эластография мебошад. Маҷмӯи дуюм натиҷаи биопсия аст, ки ҳамчун меъёри тиллоӣ гирифта мешавад.

Асосҳои ҳисоб чунинанд:

- ҲП — ҳақиқатан мусбат (беморӣ ҳаст, метод нишон дод).
- ҲС — ҳақиқатан солим (беморӣ нест, метод инкор кард).
- КМ — қалбатан манфӣ (беморӣ ҳаст, метод наёфт).
- КП — қалбатан мусбат (беморӣ нест, метод нишон дод).
- Н — шумораи умумии ҳолатҳо.

Формулаҳои асосӣ:

Ҳассосият = ҲП / (ҲП + КМ) × 100 %,

Махсусият = ҲС / (ҲС + КП) × 100 %,

Дақиқӣ = (ҲП + ҲС) / Н × 100 %,

Арзиши пешгӯии мусбат = ҲП / (ҲП + КП) × 100 %,

Арзиши пешгӯии манфӣ = ҲС / (ҲС + КМ) × 100 % .

Намунаи ҳисоб. Фарз мекунем, ки дар давоми сол ______ бемор таҳқиқ шуд. Аз онҳо ______ нафар беморӣ доштанд. Натиҷаҳо дар Ҷадвали 2.6 нишон дода шудаанд.

Ҷадвали 2.6 — Ҷадвали чорҳуҷайрагии натиҷаҳо

| Натиҷа | Беморӣ ҳаст | Беморӣ нест | Ҳамагӣ |
| :--- | :-: | :-: | :-: |
| Эластография мусбат | ҲП = ______ | КП = ______ | ______ |
| Эластография манфӣ | КМ = ______ | ҲС = ______ | ______ |
| Ҳамагӣ | ______ | ______ | Н = ______ |

Пас аз гузоштани рақамҳо нишондиҳандаҳо чунин ҳисоб мешаванд:

Ҳассосият = ______ / (______ + ______) × 100 % = ______ %,

Махсусият = ______ / (______ + ______) × 100 % = ______ %,

Дақиқӣ = (______ + ______) / ______ × 100 % = ______ % .

Барои мисол, агар ҲП = 84, КМ = 16, ҲС = 72 ва КП = 28 бошад:

Ҳассосият = 84 / 100 × 100 % = 84 %,

Махсусият = 72 / 100 × 100 % = 72 %,

Дақиқӣ = 156 / 200 × 100 % = 78 % .

Ин рақамҳо фарзияанд ва танҳо тартиби ҳисобро нишон медиҳанд. Рақамҳои воқеиро бояд аз ҳисоботи муассиса гирифт.

Ҷадвали 2.7 — Намунаи ҳисоби нишондиҳандаҳо

| Нишондиҳанда | Формула | Ҳисоб | Натиҷа |
| :--- | :--- | :--- | :-: |
| Ҳассосият | ҲП / (ҲП + КМ) | 84 / (84 + 16) | 84 % |
| Махсусият | ҲС / (ҲС + КП) | 72 / (72 + 28) | 72 % |
| Дақиқӣ | (ҲП + ҲС) / Н | 156 / 200 | 78 % |
| Арзиши пешгӯии мусбат | ҲП / (ҲП + КП) | 84 / 112 | 75 % |
| Арзиши пешгӯии манфӣ | ҲС / (ҲС + КМ) | 72 / 88 | 82 % |

Аз ҷадвал дида мешавад, ки ҳассосият аз махсусият баландтар аст. Ин маънои онро дорад, ки метод бемориро камтар аз даст медиҳад. Вале баъзан одами солимро шубҳанок нишон медиҳад. Аз ин рӯ, натиҷаи мусбат бояд бо усулҳои иловагӣ тасдиқ шавад.

Ҳисоби арзиши пешгӯӣ барои ду гурӯҳи беморон фарқ мекунад. Дар гурӯҳи хатари баланд арзиши мусбат зиёд мешавад. Дар гурӯҳи хатари паст бошад, ҳатто дақиқии баланд натиҷаи мусбати кам медиҳад. Ин ҳолат бояд ҳангоми тафсир ба назар гирифта шавад.


Дақиқии ҳақиқӣ ҳеҷ гоҳ як рақами устувор нест. Ҳар ченак хатои худро дорад. Аз ин рӯ, дар таҳқиқот интервали эътимод низ ҳисоб мешавад. Формулаи оддии он чунин аст:

ИЭ = p ± 1,96 × √(p(1 − p) / n) ,

ки дар он p — ҳиссаи нишондиҳанда ва n — шумораи ҳолатҳо.

Намунаи ҳисоб. Агар ҳассосият 84 % (p = 0,84) ва n = 100 бошад:

ИЭ = 0,84 ± 1,96 × √(0,84 × 0,16 / 100) = 0,84 ± 0,072 .

Яъне, ҳассосияти ҳақиқӣ бо эҳтимолияти 95 % дар фосилаи 76,8 % то 91,2 % аст. Ин рақам нишон медиҳад, ки натиҷа чӣ қадар боэътимод аст. Дар намунаи хурд фосила васеъ мешавад.

Ҷадвали 2.8 — Интервали эътимоди нишондиҳандаҳо

| Нишондиҳанда | Қимат, % | ИЭ, % | Фосила |
| :--- | :-: | :-: | :--- |
| Ҳассосият | 84 | 7,2 | 76,8–91,2 |
| Махсусият | 72 | 9,0 | 63,0–81,0 |

Ҷадвали 2.9 — Таъсири гурӯҳи беморон ба арзиши пешгӯӣ

Ҳисоб нишон медиҳад, ки ҳамин метод дар гурӯҳҳои гуногун натиҷаи гуногун медиҳад. Аз ин рӯ, тавсия додан лозим аст, ки эластография ба беморони гурӯҳи хатар таъин карда шавад. Ин тартиб ҳам дақиқии ташхис ва ҳам самаранокии хароҷотро якҷоя баланд мекунад.

Ҳисоби эҳтимолият низ мумкин аст. Барои арзёбии хавфи беморӣ формулаи оддии нисбат истифода мешавад:

Эҳтимолият, % = (Шумораи ҳолатҳои мусбат / Шумораи умумӣ) × 100 % .

Намунаи ҳисоб. Агар аз 200 бемор 100 нафар беморӣ дошта бошад, эҳтимолияти пеш аз таҳқиқ 50 % мешавад. Пас аз натиҷаи мусбат он ба 75 % мерасад. Ин афзоиш аҳамияти таҳқиқро нишон медиҳад.

## 2.3. Омилҳои мушкилот дар амал

Дар татбиқи метод чанд мушкилот вуҷуд дорад. Онҳоро ба се гурӯҳ ҷудо кардан мумкин аст. Ин гурӯҳҳо мушкилоти техникӣ, мушкилоти инсонӣ ва мушкилоти ташкилӣ мебошанд.

**Мушкилоти техникӣ.** Амиқии ченак маҳдуд аст. Дар амиқии зиёда аз 8 см сифати сигнал паст мешавад. Барои беморони фарбеҳ ин маҳдудияти ҷиддӣ аст. Ҳамчунин, ҳар дастгоҳ меъёри худро дорад. Муқоисаи натиҷаҳои ду дастгоҳ бе тасҳеҳ дуруст нест.

**Мушкилоти инсонӣ.** Натиҷа ба таҷрибаи оператор вобаста аст. Тадқиқот нишон медиҳад, ки пас аз сад ченак дақиқӣ устувор мешавад [5]. Дар шароити камтаҷриба хатои ченак то 20 % мерасад. Ин рақам бояд бо тадқиқоти маҳаллӣ тасдиқ шавад.

**Мушкилоти ташкилӣ.** Протоколи ягона вуҷуд надорад. Ҳисоботҳо дар шаклҳои гуногун навишта мешаванд. Маълумот ба низоми ягони бойгонӣ ворид намешавад. Ин боиси гум шудани имконияти муқоиса мегардад.

Ҳар омил дараҷаи таъсири худро дорад, вале ду омили аввал бештар вақт ва захира талаб мекунанд. Ду омили охирон бо дастурамал ва омӯзиши кӯтоҳ ҳал мешаванд. Ҳамин тартиб дар Банди 3 ҳамчун асоси тавсияҳо истифода мешавад.

Ҳисоби талафот имкон медиҳад, ки самаранокии кор арзёбӣ шавад. Агар вақти воқеӣ аз меъёр зиёд бошад, сабабро бояд муайян кард. Одатан сабаби талафот ё техникӣ ва ё ташкилӣ мебошад. Ин ҷадвал дар Банди 3 ҳамчун нуқтаи асосии муқоисаи «пеш / баъд» хизмат мекунад.

Талафот = 16 − 10 = 6 дақиқа .

Ҳисоби пурраи талафот дар сол:

Талафот дар сол = (Талафот дар як рӯз × Рӯзҳои корӣ) / 60 .

Намунаи ҳисоб. Агар дар як рӯз ҳашт таҳқиқ ва 250 рӯзи корӣ бошад:

Талафот дар як рӯз = 8 × 6 = 48 дақиқа ,

Талафот дар сол = (48 × 250) / 60 = 200 соат .

Ин рақам ба 25 рӯзи кории ҳаштсоата баробар аст. Яъне, талафоти хурди ҳаррӯза ба як моҳи кории пурра табдил меёбад. Аз ин рӯ, ислоҳи тартиби кор самараи калон медиҳад.


Барои таҳлили сабабҳо усули оддии «чаро»-ро истифода бурдан мумкин аст. Моҳияти он оддӣ аст. Ба ҳар мушкилот панҷ маротиба саволи «чаро» медиҳем. Ҳар ҷавоб сабаби амиқтарро мекушояд. Намунаи чунин таҳлил дар Ҷадвали 2.14 оварда шудааст.

Арзёбии хатар имкон медиҳад, ки захира ба самти дуруст равона шавад. Ду хатари баланд муайян шуданд: ченаки нодуруст ва талафи вақт. Ҳар ду бо тартиби корӣ иртибот доранд. Аз ин рӯ, модели Банди 3 асосан ба ҳамин ду самт нигаронида шудааст.

Барои ҳисоби дурусти нишондиҳандаҳо шумораи ҳолатҳо бояд кофӣ калон бошад. Дар акси ҳол фарқиятҳо тасодуфӣ менамоянд.
Дар шароити муассисаи воқеӣ ҷамъоварии маълумот одатан чанд моҳ вақт мегирад. Ин кор таваҷҷуҳи махсус талаб мекунад.
Ҳар ҷадвали ҳисобӣ бояд сана, манбаъ ва масъули ҷамъоварии маълумотро низ дар бар гирад.
Натиҷаи таҳлил танҳо вақте арзиш дорад, ки муассиса онро барои қабули қарорҳои амалӣ ба кор барад.

Самти таъин ба самаранокии умумии ташхис таъсири калон мерасонад. Дар амал табиб одатан аз рӯи шикоят ва таҳқиқи оддии ултрасадо беморро ба гурӯҳи хатар ҷудо мекунад. Баъд барои гурӯҳи хатари миёна ва баланд эластография таъин карда мешавад. Ин тартиби оддӣ шумораи таҳқиқҳои беҳударо кам мекунад ва вақти табибонро сарфа менамояд. Дар шароити ноҳиявӣ, ки табиб ва дастгоҳ кам аст, чунин тартиб махсусан муҳим мебошад.

**Хулосаи банд.** Эластография дар се самти асосӣ истифода мешавад. Нишондиҳандаҳои самаранокӣ бо формулаҳои стандартӣ ҳисоб мешаванд. Арзиши пешгӯӣ ба гурӯҳи беморон вобаста аст. Мушкилот ба се гурӯҳи асосӣ ҷудо мешаванд ва ҳар яке роҳи ҳалли худро дорад. Талафи вақт дар як сол метавонад то 200 соат расад. Ин натиҷаҳо барои сохтани модели амалӣ дар Банди 3 замина мегузоранд.
