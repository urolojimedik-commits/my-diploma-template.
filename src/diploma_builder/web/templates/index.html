Система автоматизации курсовых и дипломных работ

Тема → план → реальные источники → академический текст → графики → DOCX & PDF (ГОСТ) — за минуты

1. Введите тему научной работы
Поддерживается русский язык. Чем точнее формулировка, тем лучше план и поиск источников.
Генерация занимает ~30–60 сек: поиск реальных источников + графики + сборка
Примеры тем для теста
Что умеет система
  1. Принимает тему на русском
  2. Создаёт подробный план глав (ГОСТ-структура)
  3. Ищет реальные источники через Crossref/OpenAlex (с DOI)
  4. Пишет академический текст с [@cite]
  5. Строит таблицы, графики, диаграммы (matplotlib) с подписями «Рисунок N — ...»
  6. Нумерует рисунки/таблицы, формирует список литературы по ГОСТ Р 7.0.5-2018
  7. Собирает DOCX и PDF (Times New Roman 14pt, поля ГОСТ)
  8. Поддерживает русский язык и скачивание
  9. Опционально — Quarto/Pandoc
Академическая добросовестность
Система не выдумывает DOI, статистику и результаты.
• Каждый DOI проверяется через api.crossref.org/works/{DOI}
• Графики с учебными данными подписываются: «учебный пример, данные условные»
• Реальные данные — из Росстата/ЦБ или отчётности организации (с указанием источника)
