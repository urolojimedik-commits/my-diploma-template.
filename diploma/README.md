# Система автоматизации подготовки курсовых и дипломных работ

Комплект модулей на Python, который превращает **тему** работы в готовый
**DOCX** и **PDF**: план, проверенные научные источники, академический текст,
таблицы, графики, подписи с нумерацией и список литературы по
ГОСТ Р 7.0.5-2008. Интерфейс — CLI и веб-страница со скачиванием. Язык —
русский.

> **Главное правило системы:** ничего не выдумывается. Каждый DOI проверяется
> в реестре, каждое числовое значение извлекается из проверенного источника,
> а смоделированные данные всегда подписываются как учебный пример. Если
> подтвердить утверждение нечем, в тексте появляется явная пометка
> **«ТРЕБУЕТСЯ ИСТОЧНИК»**.

## 1. Возможности

| №   | Требование                                  | Как реализовано                                                                                                                                                                               |
| --- | ------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Приём темы                                  | `python -m diploma generate --topic "..."` или веб-форма; `topic.py` разбирает тему на процесс, метод, предметную область, ключевые слова (RU/EN)                                             |
| 2   | План и структура глав                       | `outline.py`: введение → 3 главы с параграфами → заключение → список источников; заголовки строятся из частей названия, поэтому грамматически корректны                                       |
| 3   | Поиск реальных источников                   | `sources/providers.py`: **Crossref**, **Semantic Scholar**, **OpenAlex**, **arXiv** + локальный проверенный корпус `data/seed_sources.json` (работает без интернета)                          |
| 4   | Академический текст с проверяемыми ссылками | `textgen/deterministic.py` пишет только по выверенным утверждениям источника, каждое предложение со ссылкой `[@key]` → `[1]`; опционально LLM-бэкенд с жёстким запретом выдумывать            |
| 5   | Таблицы, графики, диаграммы, иллюстрации    | `figures/`: matplotlib-графики по реальным показателям, сводные таблицы, схема этапов исследования, ROC-пример                                                                                |
| 6   | Подписи и нумерация                         | `figures/registry.py`: «Рисунок 2.1 — …», «Таблица 2.2 — …» + перекрёстные ссылки «рис. 2.1»                                                                                                  |
| 7   | Список литературы                           | `sources/gost.py`: ГОСТ Р 7.0.5-2008, APA, IEEE, Vancouver; Библиография — в порядке цитирования                                                                                              |
| 8   | Итоговые DOCX и PDF                         | Pandoc + `reference.docx` (Times New Roman 14, полуторный интервал, поля 30/15/20/20 мм, номер страницы); PDF — связка Pandoc → LaTeX, а при отсутствии LaTeX — встроенный рендерер ReportLab |
| 9   | Русский язык                                | Все тексты, подписи, стили, титульный лист и содержание — на русском; кириллица обеспечена шрифтами DejaVu (PDF) и Times New Roman (DOCX)                                                     |
| 10  | Скачивание                                  | Веб-интерфейс (`web/server.py`) + ZIP-архив со всеми артефактами                                                                                                                              |

Дополнительно: HTML-предпросмотр, исходный Markdown, BibTeX, JSON с данными,
экспорт проекта **Quarto** и **протокол проверки источников** (приложение А).

## 2. Установка

```bash
cd diploma
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m diploma check      # проверка окружения
```

Pandoc поставляется пакетом `pypandoc-binary` — отдельно ставить не нужно.
LaTeX не обязателен: без него PDF собирается встроенным рендерером.

## 3. Быстрый старт

### Командная строка

```bash
# полный конвейер (офлайн, по проверенному корпусу)
python -m diploma generate --topic "Применение методов машинного обучения ..." --offline

# с параметрами титульного листа
python -m diploma generate --topic "..." \
    --author "Иванов И. И." --group "МО-41" --chair "Кафедра урологии" \
    --supervisor "Петров П. П." --institution "ФГБОУ ВО «Университет»" \
    --city "Худжанд" --year 2026 --out build/demo

# отдельные шаги
python -m diploma plan   --topic "..."
python -m diploma search --topic "..."           # поиск + проверка DOI
python -m diploma web    --port 8000             # веб-интерфейс
```

### Веб-интерфейс

```bash
python -m diploma web --port 8000     # http://localhost:8000
```

Форма → прогресс по шагам → карточки скачивания DOCX / PDF / HTML / Markdown /
BibTeX / ZIP / Quarto.

### Из Python

```python
from diploma.settings import Settings
from diploma.pipeline import run_pipeline

result = run_pipeline(Settings(
    topic="Влияние цифровизации на финансовую устойчивость предприятий",
    out_dir="build/finance",
    search_offline=True,
))
print(result.files["DOCX"], result.files["PDF"])
print(result.search_report.summary())
```

## 4. Как устроена проверка источников

1. По ключевым словам темы строятся запросы (русские термины переводятся
   словарём `ru_en.py`, неизвестные слова транслитерируются).
2. Опрашиваются Crossref → Semantic Scholar → OpenAlex → arXiv. При отсутствии
   сети они просто не дают результатов — конвейер не падает.
3. К результатам всегда добавляется локальный корпус
   `data/seed_sources.json`. Его 19 записей проверены запросами вида
   `https://api.crossref.org/works?filter=doi:<DOI>` 2026-11-09; каждая хранит
   штамп `verified_via` / `verified_at` и выверенную выдержку на русском,
   поэтому пригодна для цитирования офлайн.
4. Записи дедуплицируются по DOI, затем по названию; при конфликте
   проверенная запись вытесняет сырую.
5. Каждый источник проходит проверку (`sources/verify.py`):
   сверка метаданных с Crossref, при недоступности Crossref — регистрация DOI
   через `https://doi.org/api/handles/`.
6. **Непроверенные источники не попадают ни в текст, ни в список литературы.**
   Протокол проверки сохраняется в `verification.md` и в приложение А.

На этапе проверки были отброшены, например, DOI `10.1016/j.eururo.2012.03.054`
(метаданные не совпали: это статья не о камнях почек) и `10.1007/s40620-020-00890-3`
(не найден в реестре).

### Откуда берутся числа в графиках

- `figures/data.py::extract_metrics` извлекает значения **только** из проверенных
  фактов и выдержек: проценты, объёмы выборок, AUC. Ничего не интерполируется.
- У каждого набора данных есть поле `provenance`: `real` (реальные данные,
  указаны ключи-источники), `synthetic` (учебный пример), `diagram` (схема без
  данных). Происхождение попадает в подпись рисунка и в приложение Б.
- Пример: «Рисунок 2.2 — Сравнение значений показателей… По данным: [kim2024],
  [yildirim2021] …», а «Рисунок 2.4 — ROC-кривые (учебный пример). Учебный
  пример: данные смоделированы и не являются результатом реального
  исследования».

## 5. Состав сборки (`build/demo`)

| Файл                   | Содержание                                                                  |
| ---------------------- | --------------------------------------------------------------------------- |
| `document.docx`        | Работа в Word: титульный лист, содержание, подписи, таблицы, номер страницы |
| `document.pdf`         | Тот же документ в PDF (кириллица встроенными шрифтами)                      |
| `document.html`        | Предпросмотр с содержанием                                                  |
| `document.md`          | Исходный Markdown со ссылками `[@key]`                                      |
| `document.rendered.md` | Тот же текст с раскрытыми номерами ссылок                                   |
| `references.bib`       | Библиография BibTeX (для JabRef/Zotero/Quarto)                              |
| `quarto/`              | Готовый проект Quarto (`_quarto.yml`, `index.qmd`, CSL ГОСТ)                |
| `media/`, `data/`      | Рисунки и CSV, по которым они построены                                     |
| `verification.md`      | Протокол проверки источников                                                |
| `plan.md`              | План работы                                                                 |
| `document.json`        | Все данные конвейера в JSON                                                 |
| `diploma-build.zip`    | Архив со всем перечисленным                                                 |

## 6. Структура пакета

```
diploma/
├── diploma/
│   ├── topic.py            # 1. разбор темы
│   ├── outline.py          # 2. план и структура
│   ├── sources/            # 3. поиск, проверка, BibTeX, ГОСТ
│   │   ├── providers.py    #    Crossref / OpenAlex / arXiv / S2 / корпус
│   │   ├── verify.py       #    проверка DOI и метаданных
│   │   ├── search.py       #    запросы, дедупликация, ранжирование
│   │   ├── bibtex.py       #    экспорт и импорт BibTeX
│   │   └── gost.py         #    ГОСТ Р 7.0.5-2008 / APA / IEEE / Vancouver
│   ├── textgen/            # 4. текст: детерминированный и LLM-бэкенд
│   ├── figures/            # 5-6. данные, графики, схемы, нумерация
│   ├── render/             # 7-8. Markdown, DOCX, PDF, HTML, Quarto
│   ├── web/                # 10. веб-интерфейс и выдача файлов
│   └── pipeline.py         # оркестрация шагов 1-10
├── data/seed_sources.json  # проверенный корпус источников
├── assets/gost.csl         # стиль цитирования для Quarto/Pandoc
├── tests/                  # 18 тестов (честность данных, DOCX, PDF)
└── build/                  # результаты сборок (в .gitignore)
```

## 7. Ограничения

- Детерминированный генератор текста составляет связный академический текст,
  но **не заменяет автора**: структуру и выводы нужно вычитать и дополнить.
  Для «живого» текста подключите LLM-бэкенд
  (`--text-backend llm --llm-model ... --llm-base-url ...`, ключ в `OPENAI_API_KEY`)
  — промпт запрещает использовать что-либо, кроме переданных источников.
- Офлайн-режим цитирует только проверенный корпус. Для новой темы нужен
  интернет либо собственный BibTeX (`sources/bibtex.py::read_bibtex`).
- eLIBRARY (РИНЦ) не имеет открытого API — российские источники добавляются
  через BibTeX и проходят ту же проверку DOI.
- Встроенный PDF-рендерер не поддерживает сложные формулы и сноски на полях;
  при наличии XeLaTeX используется связка Pandoc → LaTeX.

## 8. Тесты

```bash
make test            # или: python -m unittest discover -s tests -v
```

Проверяется: корректность и проверяемость всех DOI в корпусе, отказ
непроверенным источникам, порядок нумерации ссылок, извлечение метрик только
из проверенных источников, маркировка учебных примеров, формат ГОСТ,
сборка DOCX и PDF, отсутствие выдуманных DOI в итоговом документе.
