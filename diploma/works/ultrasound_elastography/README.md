## Чӣ тавр дубора сохтан мумкин аст

```bash
cd diploma/works/ultrasound_elastography
python figures/make_figures.py     # расмҳо
python build_coursework.py         # Kori_kursi.docx, Kori_kursi.pdf, Kori_kursi.zip
```

Матн дар `text/*.md` таҳрир карда мешавад; аломатгузорӣ:

| Аломат                                                         | Маъно                                 |
| -------------------------------------------------------------- | ------------------------------------- |
| `!head Сарлавҳа`                                               | сарлавҳаи берақам (Муқаддима, Хулоса) |
| `# Боби 1. ...`                                                | боб (рақамгузорӣ худкор)              |
| `## 1.1. ...`                                                  | зербоб                                |
| `!fig калид\|сарлавҳа\|пайдоиш\|сарчашма`                      | расм                                  |
| `!tab калид\|сарлавҳа\|пайдоиш\|эзоҳ` + сатрҳои `\| а \| б \|` | ҷадвал                                |
| `- матн`                                                       | рӯйхати нуқтадор                      |
| `{src:калид}`                                                  | истинод ба манбаъ                     |
| `{fig:калид}`                                                  | истинод ба расм                       |

## Хусусиятҳои муҳими техникӣ

- **Рақамгузории худкор.** Дар DOCX рақамҳои бобҳо, зербобҳо, расмҳо ва ҷадвалҳо
  бо майдонҳои Word `SEQ` сохта шудаанд, на бо рақамҳои дастӣ: агар шумо боб ё
  расми нав илова кунед, рақамҳо худкор нав мешаванд (дар Word: Ctrl+A, сипас F9).
- **Мундариҷа** — майдони `TOC`, низ худкор нав мешавад.
- **Рақами саҳифаҳо** — майдони `PAGE`, поён дар мобайн; дар варақи унвонӣ чоп
  намешавад, вале саҳифаи 1 ба ҳисоб меравад.
- **Расмҳо.** fig3 ва fig4 аз маълумоти воқеии мета-таҳлилҳо (Friedrich-Rust 2008;
  Friedrich-Rust 2012; Bavu 2011) сохта шудаанд; fig1, fig2 ва fig5 — схемаҳои
  таълимии муаллифӣ, ки бо қайди дақиқи ин мақом оварда шудаанд.

## Қоидаҳои илмӣ

1. Ҳамаи манбаъҳо воқеӣ ва бо DOI/PMID санҷида шудаанд (29 сабт).
2. Ҳеҷ ном, DOI, омор ё натиҷаи таҳқиқот сохта нашудааст.
3. Маълумоти шахсии клиникии беморон истифода нашудааст: кор хусусияти
   таҳлили адабиётӣ дорад ва ин дар муқаддима ошкоро қайд шудааст.
4. Ҷое, ки маълумот барои хулосаи қатъӣ нокифоя бошад, ин қайд карда мешавад.
