# Этап 2. Титульный лист, ГОСТ-разметка и автоматическая нумерация в Word

Этап 2 делает то, чего не было в прежнем конвейере: **документ Word
собирается напрямую** (через python-docx), а не через Pandoc, потому что поля
Word — `SEQ`, `TOC`, `PAGE` — Pandoc не создаёт. Без полей нумерацию глав,
рисунков и таблиц приходится править руками после каждой правки текста.

Ничего из существовавшего ранее не изменено: добавлены только новые файлы
внутри `diploma/`.

### 1.1. Автоматическая нумерация

| Объект               | Как выглядит            | Поле Word                                           |
| -------------------- | ----------------------- | --------------------------------------------------- |
| Глава                | Боби 2. Мавод ва усулҳо | `{ SEQ Chapter \* ARABIC }`                         |
| Параграф             | 2.1. Тарҳи таҳқиқот     | `{ SEQ Chapter \c }.{ SEQ Section \* ARABIC \s 1 }` |
| Рисунок              | Расм 2.1 — …            | `{ SEQ Chapter \c }.{ SEQ Figure \* ARABIC \s 1 }`  |
| Таблица              | Ҷадвал 2.2 — …          | `{ SEQ Chapter \c }.{ SEQ Table \* ARABIC \s 1 }`   |
| Ссылка в тексте      | «дар расми 2.1»         | `{ SEQ Chapter \c }.{ SEQ Figure \c }`              |
| Приложение           | Замимаи А. …            | `{ SEQ Appendix \* ALPHABETIC }`                    |
| Таблица в приложении | Ҷадвал А.1 — …          | `А.{ SEQ TableA \* ARABIC \s 1 }`                   |
| Содержание           | Мундариҷа               | `{ TOC \o "1-2" \h \z \u }`                         |
| Номер страницы       | внизу по центру         | `{ PAGE }`                                          |

Почему в главе нельзя писать `\s 1`: переключатель `\s` сбрасывает счётчик
у каждого заголовка 1-го уровня, то есть **в самой главе**, — и все главы
стали бы «Боби 1». Поэтому главы считаются простым `SEQ Chapter`, а сброс
`\s 1` стоит в счётчиках параграфов, рисунков и таблиц.

Каждое поле содержит кэшированное значение (видимое до обновления) и флаг
`dirty`, поэтому Word пересчитывает номера при открытии. Содержание
обновляется по Ctrl+A, F9 — об этом напоминает подсказка в документе.

Сквозная нумерация (вместо «по главам») включается в
`config/university.yml`: `gost.numbering: continuous`.

### 1.2. Титульный лист

Реквизиты берутся из `config/university.yml`:

```
Вазорати тандурустӣ ва ҳифзи иҷтимоии аҳолии Ҷумҳурии Тоҷикистон
Муассисаи давлатии таълимии «Донишгоҳи давлатии тиббии Хуҷанд»
Факултети тиббӣ
Кафедраи ҷарроҳии умумӣ

КОРИ ХАТМКУНАНДАГОН (ВКР)

Мавзӯъ: Истифодаи усулҳои омӯзиши мошинӣ барои ташхиси автоматии бемории санги гурда
Применение методов машинного обучения … (по-русски, курсивом)

Иҷрокунанда:    Алиев А. А.
                (имзо)          (насаб, ном, номи падар)
Роҳбари илмӣ:   Петров П. П., н. и. тиб, дотсент
Муқарриз:       Каримов К. К., н. и. тиб
Мудири кафедра: Раҳимов Р. Р., д. и. тиб, профессор

Хуҷанд — 2026
```

Флаг `--frame` добавляет рамку по ГОСТ 7.32-2017 (20 мм слева, 5 мм
остальные). Титульный лист — отдельная секция: номер страницы на нём не
печатается, но сама страница входит в общую нумерацию (продолжение идёт с 2).

### 1.3. Оформление по ГОСТ

Из `config/university.yml` в документ попадают:

- страница A4, поля 30 / 15 / 20 / 20 мм;
- Times New Roman 14 pt, интервал 1,5, отступ первой строки 1,25 см;
- заголовки глав — по центру, с новой страницы; параграфы — с отступом;
- подписи рисунков — по центру под рисунком, таблиц — слева над таблицей;
- таблицы — только горизонтальные линии (ГОСТ 7.32-2017);
- список литературы — с выступающей строки (1,25 см / −0,75 см);
- номера страниц — внизу по центру.

Язык документа помечается как таджикский (`w:lang = tg-Cyrl-TJ`), поэтому
Word не подчёркивает таджикские слова как ошибки.

### 1.4. Данные по-прежнему не выдумываются

| Происхождение | Что печатается под рисунком/таблицей            |
| ------------- | ----------------------------------------------- |
| `real`        | `Сарчашма: <название> (DOI: …)`                 |
| `own_data`    | `Сарчашма: Маълумоти муаллиф`                   |
| `synthetic`   | `Намунаи таълимӣ: маълумотҳо моделсозӣ шудаанд` |
| `unknown`     | `Маълумот нокифоя`                              |

Ссылка на неизвестный источник даёт `[?]`, ссылка на неизвестный рисунок —
«Маълумот нокифоя». Ни одного числа система не придумывает.

Орфография (`lang/ortho.py`) больше не портит идентификаторы: DOI вида
`10.1155/2018/3068365` и номера разделов `1.1` остаются с точкой, а десятичные
дроби `12.5` → `12,5`.

## 2. Как пользоваться

```bash
cd diploma
python make_docx_demo.py                       # build/stage2/document.docx
python make_docx_demo.py --frame               # + рамка на титульном листе
python make_docx_demo.py --continuous          # сквозная нумерация рисунков
python make_docx_demo.py --lang ru             # русский вариант подписей
```

Из кода:

```python
from diploma.render.content import MedicalDocument, Heading, Para, FigureBlock
from diploma.render.docx_med import build_docx

doc = MedicalDocument()
doc.add(TitlePage(work_type="diploma", topic="…", author="…", supervisor="…"))
doc.add(TOC())
doc.add(Heading("Муқаддима", numbered=False))
doc.add(Para("Матн бо истинод ба {src:turk2016} ва расми {fig:fig1}."))
doc.add(Heading("Баррасии адабиёт", level=1))
doc.add(FigureBlock(key="fig1", path="media/fig1.png", caption="…", provenance="synthetic"))
build_docx(doc, "build/document.docx", citation_map={"turk2016": 1})
```
