# Этап 1. Таджикский язык, медицинская структура IMRAD, библиография по ГОСТ

Этап 1 закладывает фундамент: язык документа, структуру медицинской работы,
терминологию, сокращения и правила оформления списка литературы.
Ничего из уже существовавшего в репозитории не изменено и не удалено —
добавлены только новые файлы внутри `diploma/`.

---

## 1. Что сделано

### 1.1. Таджикский язык (`diploma/diploma/lang/`)

| Файл               | Назначение                                                                                                 |
| ------------------ | ---------------------------------------------------------------------------------------------------------- |
| `lang/base.py`     | Базовый класс `Language`: названия разделов, подписи «Расм/Ҷадвал», перекрёстные ссылки, форма чисел, даты |
| `lang/tg.py`       | Таджикский: 90+ служебных терминов, месяцы, тире, десятичная запятая, «Маълумот нокифоя»                   |
| `lang/ru.py`       | Русский (для двуязычной аннотации и русскоязычных работ)                                                   |
| `lang/ortho.py`    | Орфография и типографика: проверка и автоисправление текста                                                |
| `lang/__init__.py` | `get_language("tg")` — выбор языка                                                                         |

Примеры:

```python
from diploma.lang import get_language
tg = get_language("tg")

tg.t("references")          # «Рӯйхати адабиёт»
tg.chapter_title("2", "Мавод ва усулҳо")
                            # «Боби 2. Мавод ва усулҳо»
tg.figure_caption("2.1", "Таҳлили натиҷаҳо")
                            # «Расм 2.1 — Таҳлили натиҷаҳо.»
tg.ref("fig", "2.1", capitalize=True)
                            # «Расми 2.1»
tg.number(12.5, 1)          # «12,5»
tg.percent(37.25)           # «37,3 %»
tg.p_value(0.001)           # «p<0,05»
tg.missing_data()           # «Маълумот нокифоя»
```

**Орфография** (`lang/ortho.py`, правила в `data/orthography.tg.yml`):

```python
from diploma.lang.ortho import get_orthography
o = get_orthography()

o.normalize("12.5%-ро - ин")     # «12,5 %-ро — ин»
o.check("Беморон 12.5%")          # [decimal_comma, percent_space]
o.check_heading("1.1. Усулҳои ташхис.")
                                  # [heading_dot] — точка в конце заголовка
o.fix_heading("1.1. усулҳои ташхис.")  # «1.1. усулҳои ташхис»
```

Проверяется: десятичная запятая, пробел перед `%`, пробел после запятой,
тире как `—`, отсутствие точки в конце заголовка, отсутствие `ъ/ы/ь`
в исконно таджикских словах (кроме заимствований: объект, субъект).

### 1.2. Медицинская структура IMRAD (`diploma/diploma/structure/`)

| Файл                         | Назначение                                                           |
| ---------------------------- | -------------------------------------------------------------------- |
| `structure/sections.py`      | Порядок разделов, нумерация глав/параграфов/рисунков                 |
| `structure/medical.py`       | Профиль «Медицина», план IMRAD, политика данных, проверка требований |
| `structure/abbreviations.py` | Рӯйхати ихтисораҳо: поиск, расшифровка при первом употреблении       |

Структура диплома (4 главы, IMRAD):

```
Варақи унвонӣ                        (титульный лист)
Мундариҷа                            (содержание)
Аннотатсия                           (аннотация, tg + ru)
Рӯйхати ихтисораҳо                   (список сокращений)
Муқаддима                            (введение)
Боби 1. Баррасии адабиёт             (обзор литературы)
    1.1. Вазъи муосири масъала
    1.2. Усулҳои мавҷудаи ташхис ва муолиҷа
    1.3. Истифодаи технологияҳои иттилоотӣ дар тиб
Боби 2. Мавод ва усулҳои таҳқиқот    (Materials and Methods)
    2.1. Тарҳи таҳқиқот ва хусусияти беморон
    2.2. Усулҳои таҳқиқот
    2.3. Усулҳои коркарди оморӣ
Боби 3. Натиҷаҳои таҳқиқот           (Results)
    3.1. Хусусияти умумии беморон
    3.2. Натиҷаҳои асосӣ
    3.3. Таҳлили зергурӯҳҳо
Боби 4. Муҳокимаи натиҷаҳо           (Discussion)
    4.1. Муқоиса бо маълумотҳои адабиёт
    4.2. Маҳдудиятҳои таҳқиқот
Хулоса                               (заключение, нумерованное)
Тавсияҳои амалӣ                      (практические рекомендации)
Рӯйхати адабиёт                      (список литературы)
Замимаҳо                             (приложения)
```

Курсовая работа — 2 главы (обзор + материалы/методы/результаты с обсуждением),
магистерская — 4 главы, как диплом.

Нумерация: главы — «Боби 1», параграфы — 1.1, 1.2; рисунки и таблицы —
по главам («Расм 2.1», «Ҷадвал 2.2») или сквозная (переключается в
`config/university.yml`, `gost.numbering`). На этапе 2 эти номера будут
оформлены полями Word `SEQ`, то есть нумероваться автоматически.

### 1.3. Данные и их происхождение

Главное правило системы: **факты публикаций и собственные клинические данные
автора никогда не смешиваются.** Каждое утверждение помечено:

| Метка      | Значение                                               |
| ---------- | ------------------------------------------------------ |
| `source`   | из публикации (PMID/DOI)                               |
| `own_data` | собственные данные автора                              |
| `unknown`  | данных нет — в документе появляется «Маълумот нокифоя» |

Если собственных данных нет, система **не придумывает** цифр, а задаёт вопросы
(`structure.medical.questions_for_missing_data()`):

```
- Оё маълумоти шахсии клиникии шумо (файли CSV/Excel) ҳаст ё танҳо баррасии адабиёт?
- Тарҳи таҳқиқот: ояндадор, ретроспективӣ ё буришӣ?
- Меъёрҳои дохилшавӣ ва хориҷшавии беморон кадомҳоянд?
- Ҳаҷми интихоб (n) ва тарзи ташкили гурӯҳҳои муқоисавӣ?
- Кадом нишондиҳандаҳо чен карда шуданд ва бо кадом воҳидҳо?
- Давраи ҷамъоварии мавод (санаҳо) ва пойгоҳи таҳқиқот?
- Оё иҷозати Кумитаи ахлоқ ва ризоияти хаттии беморон мавҷуд аст?
```

### 1.4. Терминология и сокращения

- `data/terms.med.tg.json` — 58 терминов: таджикский ↔ русский ↔ английский,
  с вариантами и флагом `ambiguous`. Неоднозначный термин показывается
  с оригиналом и предлагает варианты (например, «ошкорсозӣ» =
  «выявление / detection»: ошкорсозӣ / муайянкунӣ / ташхис).
- `data/orthography.tg.yml` — алфавит, шрифты, пунктуация, сокращения, правила.

Список сокращений формируется автоматически по тексту:

```python
from diploma.structure.abbreviations import load_from_dictionary
lst = load_from_dictionary()
lst.scan_text("Беморон бо усули МРТ ва УЗИ ташхис шуданд.")
lst.render_lines("tg")
# ['КТ — томографияи компютерӣ (computed tomography)',
#  'МРТ — томографияи магнитӣ-резонансӣ',
#  'УЗИ — таҳқиқоти ултрасадоӣ (ultrasound)', ...]
lst.expand_first_use("Дар КТ ва боз дар КТ")
# «Дар томографияи компютерӣ (КТ) ва боз дар КТ»
```

Сокращение без расшифровки не выдумывается, а показывается автору
(`lst.check_undefined()`).

### 1.5. Библиография по ГОСТ (`diploma/diploma/sources/gost_med.py`)

Надстройка над `sources/gost.py` с медицинскими требованиями:

- в описание добавляется **PMID**;
- запись **без DOI и без PMID в список не попадает**;
- непроверенная запись (нет отметки Crossref/PubMed) в текст не включается;
- клинические рекомендации (ВОЗ, МЗ РТ, EAU, ESC, AHA, KDIGO, NICE) определяются
  автоматически и помечаются;
- названия и фамилии сохраняются в языке оригинала (требование ГОСТ Р 7.0.5-2008).

Пример:

```
1. Turk C. EAU Guidelines on Diagnosis and Conservative Management of
   Urolithiasis // Eur Urol. — 2016. — Vol. 69. — P. 468-474. —
   DOI: 10.1016/j.eururo.2015.07.040. PMID: 26318714. (Дастурамали клиникӣ).
```

## 2. Настройки

| Файл                      | Что правит пользователь                                                                                                                                                                      |
| ------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `config/university.yml`   | **Реквизиты университета** (министерство, вуз, факультет, кафедра, город), поля страницы, шрифт Times New Roman 14 pt, интервал 1,5, набор ГОСТ, объёмы по типу работы, обязательные разделы |
| `config/medicine.yml`     | Профиль «Медицина»: число глав, правила IMRAD, политика данных, базы источников, статистика (`M±SD`, `Me [Q1; Q3]`, `p<0,05`, `95 % ДИ`)                                                     |
| `config/work.example.yml` | Шаблон описания конкретной работы → скопировать в `config/work.yml` и заполнить (тема, автор, группа, руководитель, наличие своих данных)                                                    |

Код при настройке менять не нужно.
