    Как это работает

    1. План строится из темы: главы, параграфы, цели разделов.
    2. Источники ищутся в Crossref / Semantic Scholar / OpenAlex / arXiv; офлайн используется локальный проверенный корпус.
    3. Проверка: каждый DOI сверяется с реестром. Непроверенные источники в текст не попадают — вместо ссылки ставится пометка «ТРЕБУЕТСЯ ИСТОЧНИК».
    4. Графики строятся по реальным показателям из проверенных работ либо по данным, явно помеченным как учебный пример.
    5. Выдача: DOCX, PDF, HTML, BibTeX, исходный Markdown, проект Quarto, ZIP.
    Не выдумываем источники, DOI и статистику. Проверяйте результат перед сдачей.
