# Примеры работ

## demo_цифровизация — «Цифровая трансформация государственного управления в РФ»

**Тип:** диплом (70 стр.) • **Дисциплина:** Информационные системы • **Автор:** Иванов И.И., ИВТ-21

Сгенерировано командой:
```bash
PYTHONPATH=src python scripts/generate_example.py \
  --topic "Цифровая трансформация государственного управления в Российской Федерации" \
  --type диплом --output examples/demo_цифровизация
```

### Артефакты (проверьте скачиванием)
- [thesis.docx](demo_цифровизация/thesis.docx) — 808 КБ, 8 рисунков, 2 таблицы, ГОСТ
- [thesis.pdf](demo_цифровизация/thesis.pdf) — 1.1 МБ, поля 30-15-20-20, нумерация
- [plan.md](demo_цифровизация/plan.md) — подробный план с кластером IT
- [references.bib](demo_цифровизация/references.bib) — 15 реальных DOI
- [bibliography_gost.txt](demo_цифровизация/bibliography_gost.txt) — ГОСТ Р 7.0.5-2018
- [sources.json](demo_цифровизация/sources.json) — метаданные источников
- [images/](demo_цифровизация/images/) — 8 PNG 300 DPI с подписями

```bash
python -c "from docx import Document; d=Document('examples/demo_цифровизация/thesis.docx'); print('параграфов', len(d.paragraphs))" # → 232

ls -lh examples/demo_цифровизация/thesis.pdf # → 1.1M
```

## Как создать свой пример

```bash
# Курсовая
PYTHONPATH=src python scripts/generate_example.py --topic "Маркетинг IT-продукта" --type курсовая --output examples/demo_маркетинг

# Статья
PYTHONPATH=src python scripts/generate_example.py --topic "ИИ в образовании" --type статья --output examples/demo_ии

# Веб-интерфейс
PYTHONPATH=src python -m diploma_builder.cli serve --port 8000
# → открыть http://localhost:8000
```
